# Zorykai Raids 0.1.24-quizguard.1

Durante a participação na raid, incluindo captura, o jogador não pode vencer nem receber prêmios do CRZquiz. Outros jogadores continuam participando. Depois de sair da raid, volta a responder normalmente. Não é necessário substituir o quiz.

Com o servidor parado, substitua o JAR anterior por este e mantenha somente uma versão. Requer Minecraft 1.21.1, Java 21, Fabric e Cobblemon 1.8.3. Compatibilidade de quiz validada com o CRZquiz 1.0.0 enviado. Preserva as correções anteriores de captura.

[Relatório e resultados](../../../docs/tests/quizguard-0.1.24/README.md). A integração de teste não deve ser instalada em produção.
